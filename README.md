# QR Menü (TR / EN / عربي)

1. Bu klasörün İÇİNDEKİLERİ (index.html, css, js, data, img, .nojekyll) GitHub reposunun köküne yükleyin.
   `index.html` repo kökünde olmalı; klasörün kendisini değil içindekileri yükleyin.
2. Repo > Settings > Pages > Branch: main, Folder: / (root) > Save. 1-2 dk sonra adres açılır.
3. Yönetim paneli: site adresinin sonuna `#yonetim` ekleyin (şifre: admin123 — Ayarlar'dan değiştirin).
4. Dil: sağ üstteki TR / EN / ع. Arapçada sayfa sağdan sola döner. İngilizce ve Arapça fiyatlar dolardır (Ayarlar > Diller & Dolar'dan kur girilir; isterseniz ürün bazında $ fiyat yazılır).
5. Panelde yaptığınız değişiklik taslaktır; "Yayınla & QR" sekmesinden paketi indirip repoya yükleyin.
